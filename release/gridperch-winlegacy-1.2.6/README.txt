GridPerch 采集端 —— Windows 旧系统兼容版 1.2.6
=====================================================

一、这个包是干什么的
--------------------
把本机接入 GridPerch 运维监控平台，注册为开机自启的后台任务。

包里的 gridperch-agent.exe 是 **Go 1.20 构建的旧系统兼容版**，专门用来解决：
正式版采集端在旧 Windows 上双击后窗口一闪就消失、没有日志也没有报错的问题。

原因：Go 1.21 起的程序要求 Windows 10 / Server 2016 以上。旧系统上 runtime
初始化时调不到 bcryptprimitives.dll 里的 ProcessPrng，直接崩在 0xc0000005，
崩得太早，连日志都来不及写。换工具链是唯一解，打补丁解决不了。


二、适用系统（64 位）
--------------------
    Windows Server 2008 R2
    Windows Server 2012 / 2012 R2
    Windows Server 2016
    Windows 7 SP1 / 8 / 8.1 / 10 / 11（这些系统也能用，只是本来不需要兼容版）

⚠️ 不支持 32 位（x86）系统。本包内是 64 位程序。
   若目标机器是 32 位 Server 2008，需要单独构建 windows/386 版本。

⚠️ Windows Server 2008（非 R2，内核 6.0）不在官方支持范围。本包最低要求
   2008 R2（内核 6.1）。2008 RTM 一般也能跑起来，但未做验证，请先试装一台。


三、安装（两步，全程不需要输入任何东西）
----------------------------------------
本包是**站点专用包**：平台地址和通信密钥已经写死在 install.ps1 顶部，双击即装。

1) 把整个压缩包解压到目标机器任意目录。
   ⚠️ 必须整个解压，install.ps1 和 gridperch-agent.exe 要在同一层目录里，
      只拷 bat 或只拷 exe 都会失败。

2) 右键 install.bat → 「以管理员身份运行」。
   （直接双击也会自动申请提权，但部分老系统 UAC 弹窗会被策略拦住，右键更稳。）

   脚本会自己走完：校验环境 → 复制程序到 C:\GridPerch → 注册开机自启 →
   立即启动，中途不会问任何问题。

   装完到控制台「主机监控」看本机是否上线，通常 10 秒内出现。

   主机名默认就是本机的计算机名（如 WIN-8A3K2L）。想在平台上显示成
   「财务服务器」这类名字，直接在控制台里改名即可 —— 平台会把历史数据
   一起迁到新名下，不会产生重复主机。


本包内置的连接信息（要改就改 install.ps1 顶部那两行，然后重新打包）
--------------------------------------------------------------------
    平台地址     http://192.168.40.111:9999
    通信密钥MD5  ffb977235c34019e5a27f12639a21126

    ⚠️ 包里带的是明文/固定密钥，只适合内网内部流转，不要外发。


四、指到别的平台或改名安装（可选）
----------------------------------
本包默认连上面那个地址。要让某个包连别的平台，改 install.ps1 顶部：

    $BuiltinServer    = 'http://新地址:9999'
    $BuiltinTokenHash = '新平台的 32 位 wgToken'

也可以用参数临时覆盖（先以管理员身份打开「命令提示符」再执行）：

    install.bat -Server http://192.168.1.10:9999 -Token gridperch

可选参数：
    -Name       指定在平台上显示的主机名（默认取本机计算机名）
    -TokenHash  直接给 32 位 MD5，脚本就不再从明文口令算
    -InstallDir 安装目录，默认 C:\GridPerch

⚠️ 带参数时必须在「管理员」命令提示符里执行。若在普通窗口执行，脚本
   提权时参数会带不过去，最后变成交互式询问。


五、装完之后的几个关键事实
--------------------------
1) 采集端被注册成计划任务 gridperch-agent，SYSTEM 身份、开机自启、
   不限运行时长（计划任务默认跑满 72 小时会被强杀，这里已经放开）。

2) 启动参数里固定带了 -update off -remote-config off 两个开关，
   这是**故意**的，不要删：
     -update off        关闭自动升级。平台的 updateMode 是全局默认 auto，
                        一旦放开，这台旧系统会在 30 分钟内被自动换成
                        Go 1.23 构建的正式版，换完立刻闪退起不来。
     -remote-config off 不接受平台下发的运行配置，只用装机时的本地参数。
   两个一起用，才能保证「装的时候能跑，之后一直能跑」。

   如果确实需要在平台上统一调整采集间隔/告警阈值，可以：
     · 打开「控制台 → 主机监控 → 本机 → 编辑」，改这台主机的单独配置；或
     · 把计划任务参数里的 -remote-config off 改成 auto ——
       但 -update off 必须保留。
     修改方法：控制面板 → 管理工具 → 任务计划程序 → 找到 gridperch-agent
     → 右键属性 → 操作 → 编辑，改完保存并重启任务。

3) 常用命令（管理员命令提示符）：
     schtasks /Run /TN gridperch-agent            启动
     schtasks /End /TN gridperch-agent            停止
     schtasks /Query /TN gridperch-agent /V /FO LIST   查看详情
     taskkill /IM gridperch-agent.exe /F          强制结束进程


六、卸载
--------
右键 uninstall.bat → 「以管理员身份运行」。
它会停掉并删除计划任务、结束进程、删除 C:\GridPerch 目录。
平台上的主机记录不会自动删除，需要到控制台手工删。


七、出问题了怎么查
------------------
■ 装完控制台一直看不到主机
  1. 确认采集端进程在跑：任务管理器里找 gridperch-agent.exe；
  2. 在安装目录手工前台运行一次，让报错直接打在屏幕上：
         cd /d C:\GridPerch
         gridperch-agent.exe -server http://你的平台地址:9999 -token-hash <那串MD5>
     能打日志却不报错 → 是网络/地址问题；仍然一闪而过 → 二进制与系统不匹配；
  3. 检查本机到平台 9999/TCP 是否通：
         powershell -Command "Test-NetConnection 平台IP -Port 9999"
     （Server 2008 R2 没有 Test-NetConnection，可用 telnet 平台IP 9999）
  4. 平台地址不要填 127.0.0.1 或 10.x / 192.168.x 内网 IP ——
     除非本机就在那个网段里，否则别的机器连不上；
  5. 云主机场景，平台侧要设 -public-url 为公网地址，安全组放行 9999/TCP。

■ 提示「通信密钥校验失败」/ 平台判定未授权
  包内写死的密钥和平台当前口令对不上，通常是平台口令后来被改过。
  到平台「添加主机」页复制 wgToken（32 位十六进制），然后二选一：
    · 改 install.ps1 顶部的 $BuiltinTokenHash，重新打包分发；
    · 或本次临时指定：install.bat -TokenHash <那串32位>（管理员窗口执行）。

■ 提示计划任务注册失败
  本包注册自启走两条路：
    ① 新系统（Win8 / Server 2012 起）用计划任务 API；
    ② 旧系统（Server 2008 R2 只有 PowerShell 2.0，没有该 API）改用
       「任务 XML + schtasks /Create /XML」注册。
  第 ② 条是 1.2.6 修的：早期版本用 schtasks /Create /TR，在 Server 2008 R2
  上会报「无效参数/选项 - '-server'」（/TR 的值含空格和引号，被两边各转义
  一次后就断了）。XML 把程序、参数、工作目录拆成三个独立元素，不经过命令行
  引号规则，所以不会再出现这个问题。

  万一两条路都失败，屏幕会打印生成的 XML 路径和一条手工注册命令，
  照抄到管理员命令提示符执行即可。

■ 装完过一段时间自己不见了 / 版本号变了
  检查计划任务参数里的 -update off 是否还在。被改回 auto 的在旧系统上
  会升级成跑不起来的版本。


八、包内文件
------------
    gridperch-agent.exe   采集端程序（Go 1.20 兼容版，64 位）
    install.ps1           实际安装脚本（兼容 PowerShell 2.0）
    install.bat           安装入口（自动提权）
    uninstall.bat         卸载脚本
    SHA256SUMS.txt        校验和
    README.txt            本文件

校验文件是否损坏（Windows 自带）：
    certutil -hashfile gridperch-agent.exe SHA256
把输出与 SHA256SUMS.txt 里的值对照，忽略大小写和空格。
